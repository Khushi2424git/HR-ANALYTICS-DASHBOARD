# 📊 HR Analytics Dashboard (Excel)

An interactive **HR Analytics Dashboard** built in Microsoft Excel to analyze employee attrition and workforce trends across departments.


## 🎯 Objective
To help HR teams understand **why employees leave**, which departments are affected, and how factors like income, age and business travel relate to attrition.

## 📌 Key Metrics (KPIs)
| Metric | Value |
|---|---|
| Total Employees | 1,470 |
| Employees Left (Attrition = Yes) | 237 |
| Current Employees (Attrition = No) | 1,233 |
| Average Age | 37 years |
| Average Monthly Income | 6,503 |
| Attrition Rate | ~16% |

## 📈 Dashboard Components
- **KPI Cards** – Total, current and departed employees, average age, average income
- **Attrition by Department** – Bar chart comparing Sales, R&D and HR
- **Business Travel by Department** – Area chart (Non-Travel, Travel Frequently, Travel Rarely)
- **Workforce by Department** – Column chart
- **Employee Status** – Donut chart (Attrition Yes vs No)

## 🛠️ Tools & Techniques
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Data cleaning and formulas
- Dashboard design (dark theme, KPI cards)

## 🔍 Key Insights
- About **16% of employees** have left the company.
- **R&D** is the largest department, so it has the highest overall numbers.
- Most employees **travel rarely**, and Sales and R&D show more travel than HR.
- Average employee age is **37**, which suggests a mid-career workforce.

## 📂 Files
- `HR_DATA_DASHBOARD.xlsx` – Excel file with data, pivots and dashboard

## 🚀 How to Use
1. Download `HR_DATA_DASHBOARD.xlsx`.
2. Open it in Microsoft Excel (2016 or later).
3. Go to the Dashboard sheet and use slicers/filters to explore.
